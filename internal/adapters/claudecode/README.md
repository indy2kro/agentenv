`~/.claude/settings.json`) and the `CLAUDE.md` pointer file (see
`docs/plans/agentenv-dev-plan.md` §4, §5).

acceptance criterion), using the findings in
`docs/research/agent-adapters.md` and `docs/research/rtk-init-behavior.md`
(Phase 0 Tasks 3-4).
